# ⚡ FlashAPI

**FlashAPI** is a powerful, lightweight, and asynchronous-first Rust crate.

This repository contains the official documentation for interacting with the FlashAPI backend.

## 🚀 Getting Started

This guide will help you get the documentation and example frontend up and running on your local machine.

### Prerequisites

- Node.js (v20 or higher)
- pnpm
- Rust and Cargo (for the FlashAPI backend, not covered here)

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/flashapi-documentation.git
    cd flashapi-documentation
    ```

2.  **Install dependencies:**
    This project uses `pnpm` for package management.
    ```bash
    pnpm install
    ```

### Running the Development Server

To start the Next.js development server, run:

```bash
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
